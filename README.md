# 🎼 箏 文化譜エディタ (Koto Note)

十三絃箏（こと）の **文化譜（数字譜）** をブラウザで「作る・聴く・編集する・印刷する・音声/MIDI書き出し」ができる本格Webエディタです。
スマートフォン・タブレット・PCのあらゆる画面サイズに対応し、縦書き文化譜および横書き譜の両方で快適に操作・作曲・練習ができます。

---

## 🌟 主な特徴

- **伝統的な縦書き文化譜（右→左）＆ 横書き譜の切り替え**
  - 文化譜本来の右から左へ流れる縦書きレイアウト。
  - 列の途中で不自然に折り返されることのない連続スクロール表示。
  - 1列あたりの小節数を「2小節（スマホ・縦画面に最適）」「4小節」など自由に切り替え可能。
- **高品位な実機物理モデリング音源（Karplus-Strong 撥弦モデル）**
  - 絹糸・テトロン糸の振動、龍角寄りの打弦位置、象牙爪のアタック音、桐胴の共鳴特性をWeb Audio APIで再現。
  - 左手奏法（オ・ヲ押し手、ア後押し、ハ押し放し、ヒ引き色、ツ突き色、ユ揺り色）の音程変化（ピッチベンド）に対応。
  - 右手爪技法（スクイ爪、掻き爪、引き爪、トレモロ、流し爪）のニュアンスを再生音に反映。
- **音源・楽譜データの書き出し（WAV / MIDI / JSON / PDF）**
  - **WAV音声書き出し**: ブラウザ内でオフライン合成し、演奏全体を高音質WAVファイルとしてダウンロード。
  - **MIDI書き出し (.mid)**: DAWや楽譜ソフトへ直接連携可能。
  - **JSON保存・読み込み**: 譜面データの保存や共有、ドラッグ＆ドロップでの読み込み。
  - **印刷 / PDF出力**: 編集UIを隠した清書文化譜をA4縦・横で出力。
- **仮想十三絃 箏盤（インタラクティブ演奏ビジュアライザー）**
  - 一〜巾の13本の絃と琴柱（柱の位置は調弦の音高比率に応じて動的に配置）を表示。
  - クリック/タップで試奏・入力できるほか、再生中は鳴っている絃がリアルタイムに光って振動。
- **小節クイックナビゲーター ＆ 画面自動追従**
  - 上部の小節バー `[1] [2] ... [14] [＋]` をタップするだけで目的の小節へ即座にジャンプ。
  - 再生中やカーソル移動時は、アクティブなマスが自動的に画面中央へスムーズ追従。
- **必要な時だけ出る奏法の行**
  - 音を入れた直後（または音のあるマスを選んだとき）だけ、絃キーの上に「八に：オ ヲ ア ス ユ …ほか」と出ます。押すとその音に付き、すぐ試聴できます。
  - 「…ほか」で、ほかの左手・右手の奏法と指番号を開けます。行の高さはいつも確保しているので、絃キーの位置はずれません。
- **親指で操作できる下部固定入力パレット**
  - 画面下部に「一〜巾」「♩・♪♪・3連・♬」「休符・延ばし・消す」「奏法」「小節操作」を集約。
  - 画面を上下に往復スクロールすることなく、譜面を見ながら手元で快適に入力可能。
- **調弦（ちょうげん）詳細設定**
  - 平調子・雲井調子・中空調子・乃木調子・古今調子・楽調子・カスタム調弦。
  - 基音（一の音）の十二律変更、全体移調（半音シフト）、各絃周波数（Hz）表示＆個別試聴。
- **古典名曲プリセット ＆ マイ楽曲保存**
  - 「さくらさくら」「六段の調（初段）」「荒城の月」をすぐに呼び出し可能。
  - ブラウザのLocalStorageに複数曲を保存・管理可能。

## 🎹 キーボード操作（PC向け）

物理キーの位置で判定するので、日本語入力がONでも、JIS・US どちらの配列でも同じように動きます。
ポップアップ（調弦・楽曲集・保存・ヘルプ・新規作成）や演奏モードが開いている間は、裏の譜面は操作されません。

| 操作 | キー |
|---|---|
| **弦 一〜巾（数字列）** | `1` `2` `3` `4` `5` `6` `7` `8` `9` `0` `-` `^` `¥` |
| **弦 一〜為（ホーム列）** | `A` `S` `D` `F` `G` `H` `J` `K` `L` `;` `:` `]`（巾は `@`） |
| **十七絃の14〜17本目** | `Alt` + `1`〜`4`（十七絃の楽譜のときだけ） |
| **和音（合わせ手）** | `Shift` を押しながら弦キー |
| **音の長さ** | `Q` 4分　`W` 8分　`E` 3連　`R` 16分（次の拍にも引き継がれます） |
| **休符 ／ 延ばし** | `P` または `.` ／ `T` または `,`（入れたら次のマスへ進みます） |
| **押し手** | `Z` 半音（オ）　`X` 全音（ヲ） |
| **後押し・押し放し・引き色・突き色・揺り色** | `Y` `U` `I` `O` `M` |
| **スクイ・掻き爪・引き爪・トレモロ・流し爪** | `C` `V` `B` `N` `/` |
| **移動** | 矢印キー、`Enter` 次の小節へ、`Home` `End` 先頭・末尾 |
| **範囲選択** | マウスでドラッグ、`Shift`+クリック／矢印、`Ctrl`+クリックで追加、`Ctrl`+`A` 全選択 |
| **消す** | `Delete`（そのマス／選択範囲）、`Backspace`（空のマスなら1つ戻ってから消す） |
| **再生** | `Space` 再生／一時停止（停止位置にカーソルが移ります）、`Shift`+`Space` カーソルから、`Esc` 停止 |
| **元に戻す / やり直し** | `Ctrl`+`Z` ／ `Ctrl`+`Y` |
| **コピー / 切取 / 貼付** | `Ctrl`+`C` ／ `Ctrl`+`X` ／ `Ctrl`+`V` |
| **新規 / 印刷 / 保存** | `Ctrl`+`N` ／ `Ctrl`+`P` ／ `Ctrl`+`S` |

## 🖨 印刷のコツ

- 縦書きの長い曲は、用紙の幅で折り返して複数ページに分かれます。「設定」の **用紙**（A4 縦／横）で向きを選べます。
- 印刷ダイアログで「ヘッダーとフッター」のチェックを外すと、URLや日付が消えてきれいに仕上がります。
- 選択中のマスの枠や再生位置の表示は、印刷には出ません。

## 🛠 開発とビルド

```bash
npm install        # 依存関係のインストール
npm run dev        # 開発サーバー起動（Vite）
npm run build      # プロダクションビルド
npm run lint       # 型チェック
npm test           # 自動テスト（再生の時間表・奏法の展開・MIDI・データ検査）
```

### 内部の構成（再生と書き出し）

- `src/audio/timeline.ts` … 譜面を「何拍目に・どの音を・何拍ぶん」の時間表にする（くり返し記号の解決を含む）
- `src/audio/voicing.ts` … 奏法記号（トレモロ・掻き爪・流し爪など）を実際の発音に展開する
- `src/audio/player.ts` … 画面での再生（先読みスケジューラ。再生中の編集・速さ変更も反映）
- `src/utils/wavExport.ts` / `midiExport.ts` … 上の時間表と発音を使って書き出す（画面で聴こえる音と同じになります）

## 🔎 公開と検索エンジン

- `index.html` に、検索結果に出るタイトル・説明文、SNS共有用の情報、Googleの所有権確認タグ（`google-site-verification`）、構造化データ（JSON-LD）を入れています。
- JavaScript を読まない検索ロボット向けに、アプリが起動するまでの間に表示される本文（機能の説明）も入れています。
- `public/robots.txt`（クロールの許可）・`public/sitemap.xml`・`public/og-image.png`（共有用の画像）は、ビルド時にそのまま公開されます。
- 公開URLは `https://koto-simulator.axw-nkt-fno.workers.dev/` です。URLを変えたときは、`index.html` の canonical / og:url / og:image、`public/sitemap.xml`、`public/robots.txt` を書き換えてください。

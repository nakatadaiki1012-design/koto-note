# 🎼 箏 文化譜エディタ (Koto Note)

十三絃箏（こと）の **文化譜（数字譜）** をブラウザで「作る・聴く・編集する・印刷する・音声/MIDI書き出し」ができる本格Webエディタです。
スマートフォン・タブレット・PCのあらゆる画面サイズに対応し、縦書き文化譜および横書き譜の両方で快適に操作・作曲・練習ができます。

---

## 🌟 主な特徴

- **伝統的な縦書き文化譜（右→左）＆ 横書き譜の切り替え**
  - 文化譜本来の右から左へ流れる縦書きレイアウト。
  - 列の途中で不自然に折り返されることのない連続スクロール表示。
  - 1列あたりの小節数を「2小節（スマホ・縦画面に最適）」「4小節」など自由に切り替え可能。
- **高品位な実機物理モデリング音源（Karplus-Strong 撥弦モデル）**
  - 絹糸・テトロン糸の振動、龍角寄りの打弦位置、象牙爪のアタック音、桐胴の共鳴特性をWeb Audio APIで再現。
  - 左手奏法（オ・ヲ押し手、ア後押し、ハ押し放し、ヒ引き色、ツ突き色、ユ揺り色）の音程変化（ピッチベンド）に対応。
  - 右手爪技法（スクイ爪、掻き爪、引き爪、トレモロ、流し爪）のニュアンスを再生音に反映。
- **音源・楽譜データの書き出し（WAV / MIDI / JSON / PDF）**
  - **WAV音声書き出し**: ブラウザ内でオフライン合成し、演奏全体を高音質WAVファイルとしてダウンロード。
  - **MIDI書き出し (.mid)**: DAWや楽譜ソフトへ直接連携可能。
  - **JSON保存・読み込み**: 譜面データの保存や共有、ドラッグ＆ドロップでの読み込み。
  - **印刷 / PDF出力**: 編集UIを隠した清書文化譜をA4縦・横で出力。
- **仮想十三絃 箏盤（インタラクティブ演奏ビジュアライザー）**
  - 一〜巾の13本の絃と琴柱（柱の位置は調弦の音高比率に応じて動的に配置）を表示。
  - クリック/タップで試奏・入力できるほか、再生中は鳴っている絃がリアルタイムに光って振動。
- **小節クイックナビゲーター ＆ 画面自動追従**
  - 上部の小節バー `[1] [2] ... [14] [＋]` をタップするだけで目的の小節へ即座にジャンプ。
  - 再生中やカーソル移動時は、アクティブなマスが自動的に画面中央へスムーズ追従。
- **親指で操作できる下部固定入力パレット**
  - 画面下部に「一〜巾」「♩・♪♪・3連・♬」「休符・延ばし・消す」「奏法」「小節操作」を集約。
  - 画面を上下に往復スクロールすることなく、譜面を見ながら手元で快適に入力可能。
- **調弦（ちょうげん）詳細設定**
  - 平調子・雲井調子・中空調子・乃木調子・古今調子・楽調子・カスタム調弦。
  - 基音（一の音）の十二律変更、全体移調（半音シフト）、各絃周波数（Hz）表示＆個別試聴。
- **古典名曲プリセット ＆ マイ楽曲保存**
  - 「さくらさくら」「六段の調（初段）」「荒城の月」をすぐに呼び出し可能。
  - ブラウザのLocalStorageに複数曲を保存・管理可能。

## 🎹 キーボード操作（PC向け）

| 操作 | キー |
|---|---|
| **弦 一〜巾（数字列）** | `1` `2` `3` `4` `5` `6` `7` `8` `9` `0` `-` `^` `¥` |
| **弦 一〜為（ホーム列）** | `A` `S` `D` `F` `G` `H` `J` `K` `L` `;` `:` `]`（巾は `@` または `¥`） |
| **和音（合わせ手）** | `Shift` を押しながら弦キー |
| **音の長さ** | `Q` 4分　`W` 8分　`E` 3連　`R` 16分 |
| **休符 ／ 延ばし** | `P` または `.` ／ `T` または `,` |
| **押し手** | `Z` 半音（オ）　`X` 全音（ヲ） |
| **後押し・押し放し・引き色・突き色・揺り色** | `Y` `U` `I` `O` `M` |
| **スクイ・掻き爪・引き爪・トレモロ・流し爪** | `C` `V` `B` `N` `/` |
| **小節移動 / 範囲選択** | `Enter` ／ `Shift`+クリック（`Esc`で解除） |
| **消す** | `Delete` このマス　`Backspace` 戻りながら消す |
| **再生** | `Space` 再生/一時停止　`Shift`+`Space` カーソルから再生　`Esc` 停止 |
| **元に戻す / やり直し** | `Ctrl`+`Z` ／ `Ctrl`+`Y` |
| **小節コピー / 貼付** | `Ctrl`+`C` ／ `Ctrl`+`V` |

# 🎼 箏 文化譜エディタ

十三絃箏（こと）の **文化譜（数字譜）** をブラウザだけで「作る・聴く・印刷する」ためのアプリです。
インストール不要・サーバー不要の **HTMLファイル1つ（`index.html`）** で動きます。

## 開き方

- いちばん簡単：`index.html` をダブルクリック（Chrome / Edge / Safari など）。
- ローカルサーバーで動かす場合（任意）：このフォルダで `python3 -m http.server 8000` を実行し、`http://localhost:8000/` を開く。

初回は「さくらさくら」のサンプルが入っています。入力した譜面はブラウザに**自動で下書き保存**され、再読み込みしても消えません。

## できること

| 分類 | 内容 |
|---|---|
| 楽曲情報 | タイトル・サブタイトル・演奏者/編曲者・テンポ（♩＝）・拍子（4/4・3/4・2/4） |
| 調弦 | 平調子・雲井調子・中空調子・乃木調子・古今調子・楽調子・カスタム調弦。基音（一の音）を半音単位で変更／全体を移調。カスタムは13本それぞれをMIDI番号か周波数(Hz)で指定 |
| 譜面 | 縦書き（右→左に列が進む、一般的な文化譜の形）と横書きを切替。1段の小節数を指定。拍は上下（横書きは左右）2マスに分かれ、8分・16分・3連符に対応 |
| 表記 | 漢数字（一〜十・斗・為・巾）⇔ 数字（1〜13）切替。ドレミ／CDE のルビ表示（押し手の音程も反映） |
| 左手の奏法 | 押し手（オ＝半音、ヲ＝全音）、後押し（ア）、押し放し（ハ）、引き色（ヒ）、突き色（ツ）、揺り色（ユ）。どれも再生の音程に反映（弾いた後に音が動く） |
| 右手の奏法 | スクイ（ス）、掻き爪（掻）、引き爪（引）、トレモロ（〰）、流し爪（流）。休符（○）、延ばし（ー）、和音（合わせ） |
| 入力の工夫 | 「入力の長さ」（4分・8分・3連・16分）が次の拍にも引き継がれる／4分音符の下半分をクリックして入れると8分に分かれる／Shift+クリックで複数小節を選んでコピー・貼付・削除・ループ |
| 再生・練習 | Web Audio API による箏の音（Karplus-Strong 撥弦モデル＋爪のアタック音＋響き）。再生／一時停止／停止／巻き戻し、再生位置のハイライト、小節番号クリックやマスのダブルクリックでそこから再生、A〜B 小節のループ、再生速度（50〜125%）、前カウント、メトロノーム |
| 保存 | JSONファイルに書き出し（Chrome/Edge では保存場所を選べる）／読み込み（画面へのドロップも可）、ブラウザへの自動下書き保存、元に戻す／やり直し |
| 印刷 | 「印刷 / PDF」ボタン（または Ctrl+P / ⌘+P）で、操作パネルを消した清書譜面を A4 縦・横で出力。各ページ下に曲名とページ番号。調弦表を譜面に載せることも可。PDF保存は印刷画面で「PDFに保存」を選ぶ |

## キーボード入力（日本語キーボード基準）

| 操作 | キー |
|---|---|
| 弦 一〜巾 | `1` `2` `3` `4` `5` `6` `7` `8` `9` `0` `-` `^` `¥` |
| 弦 一〜為（ホーム列） | `A` `S` `D` `F` `G` `H` `J` `K` `L` `;` `:` `]`（巾は `¥` または `@`） |
| 和音 | `Shift` を押しながら弦キー |
| 入力の長さ | `Q` 4分　`W` 8分　`E` 3連　`R` 16分 |
| 休符 ／ 延ばし | `P` または `.` ／ `T` または `,` |
| 押し手 | `Z` 半音（オ）　`X` 全音（ヲ） |
| 後押し・押し放し・引き色・突き色・揺り色 | `Y` `U` `I` `O` `M`（ア・ハはオ／ヲと組み合わせると上げ幅が変わる） |
| スクイ・掻き爪・引き爪・トレモロ・流し爪 | `C` `V` `B` `N` `/`（カーソルの音、空ならいま入れた音に付く） |
| 次の小節へ／範囲選択 | `Enter` ／ `Shift`+クリック（`Esc`で解除） |
| 消す | `Delete` このマス　`Backspace` 戻りながら消す |
| 再生 | `Space` 再生／一時停止　`Shift`+`Space` カーソルから再生　`Esc` 停止 |
| 元に戻す／やり直し | `Ctrl`+`Z` ／ `Ctrl`+`Y`（小節コピー `Ctrl`+`C`・貼付 `Ctrl`+`V`） |

画面下のボタン（一〜巾、奏法など）でもマウスやタッチで同じ入力ができます。

## 調弦の定義（一＝D のとき）

| 調子 | 一 | 二 | 三 | 四 | 五 | 六 | 七 | 八 | 九 | 十 | 斗 | 為 | 巾 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 平調子 | D4 | G3 | A3 | B♭3 | D4 | E♭4 | G4 | A4 | B♭4 | D5 | E♭5 | G5 | A5 |
| 雲井調子 | D4 | G3 | A♭3 | C4 | D4 | E♭4 | G4 | A♭4 | C5 | D5 | E♭5 | G5 | A5 |
| 中空調子 | D4 | G3 | A3 | B♭3 | D4 | E4 | F4 | A4 | B♭4 | D5 | E5 | F5 | A5 |
| 乃木調子 | D4 | G3 | A3 | B3 | D4 | E4 | G4 | A4 | B4 | D5 | E5 | G5 | A5 |
| 古今調子 | D4 | G4 | A3 | C4 | D4 | E♭4 | G4 | A4 | C5 | D5 | E♭5 | G5 | A5 |
| 楽調子 | D4 | G3 | A3 | C4 | D4 | E4 | G4 | A4 | C5 | D5 | E5 | G5 | A5 |

- 一と五は同じ高さ、二と三は一より低い、という箏の一般的な並びです。
- 流派や曲によって細部が違う場合は「カスタム調弦」で1本ずつ直せます。

## 文化譜の書き方の約束

- 空いているマスは「前の音を延ばす」意味です。音を止めたいときは ○（休符）を入れます。
- 押し手（オ・ヲ）は再生時に半音／全音高く鳴ります。
- 掻き爪・引き爪は「隣の弦と続けて2音」、トレモロは「その長さのあいだ細かく連打」、流し爪は「巾から順に下ってその弦で止まる」として再生します（近似です）。
- 後押し（ア）は弾いてから押し上げます。オ／ヲと一緒に付けると半音／全音、ア単独では半音上げます。押し放し（ハ）は押した高さで弾いてから元の高さへ戻します。
